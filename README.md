# Echoes_of_Exploration
An interactive educational website exploring NASA's historic and ongoing space missions through storytelling, scientific discoveries, interactive quizzes, and browser-based narration. Built with HTML, CSS, and JavaScript.

About

Echoes of Exploration brings the history of space exploration to life through interactive storytelling. Explore the missions that helped humanity discover the Moon, Mars, and deep space while learning about their technology, discoveries, and achievements.

Features

- Explore 10 historic and ongoing space missions.
- Three reading levels: Kid, Mid, and Pro.
- Interactive first-person mission stories.
- Scientific discoveries and mission highlights.
- Interactive quizzes with progress tracking.
- Browser-based text-to-speech narration.
- Mission search and destination filters.
- Responsive design for mobile and desktop.
- Local storage for saving progress and preferences.

Missions

Apollo, Sojourner, Spirit, Opportunity, Curiosity, Perseverance & Ingenuity, Pioneer, Voyager, New Horizons, and Viking.

Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas
- Web Speech API
- Local Storage API

No frameworks, backend, or paid APIs required.

Educational Purpose

This project is created for educational purposes. First-person spacecraft stories are fictional storytelling elements inspired by real space missions and scientific discoveries.
